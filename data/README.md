# Generated data

This repository deliberately does not redistribute the UCI borrower-level dataset.

Run `notebooks/credit_risk_modelling.ipynb` to download the public UCI dataset and generate the following CSV files:
- `repayment_status_uncertainty.csv`
- `model_metric_uncertainty.csv`
- `threshold_cost_scenarios.csv`

The model runs and CSVs will be recreated in the Colab working directory. Download them manually if desired; the report and README use numerical outputs verified from the author's executed screenshots.
